# Bandit Level 7 → 8

## Goal
Find the password next to the word `millionth` in `data.txt`.

## Commands Used
```bash
grep "millionth" data.txt
```

## What I Learned
- `grep` searches inside a file for a specific word or pattern
- The format is always `grep "search term" filename`
- Getting the order wrong causes the command to fail
- `grep` is one of the most useful tools for searching through files
