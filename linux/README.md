# Linux Module

## Overview
This module covers the fundamentals of Linux which is the foundation 
of everything in DevOps. Every tool used later — Docker, Kubernetes, 
CI/CD, and AWS — assumes comfort at the command line.

## What I Learned

### Core Skills
- Navigating the Linux file system confidently
- Managing files, directories and permissions
- Understanding process management and system monitoring
- Using essential Linux tools (grep, awk, sed, find)
- Working with users, groups and file ownership
- Connecting to remote servers using SSH and SSH keys
- Understanding networking basics — ports, nc, SSL, nmap

## Key Commands Reference
| Command | What it does |
|---------|-------------|
| `ssh` | Connect to a remote server securely |
| `find` | Search for files by properties |
| `grep` | Search inside files for patterns |
| `chmod` | Change file permissions |
| `nc` | Connect to network ports |
| `nmap` | Scan open ports on a server |
| `diff` | Compare two files |
| `base64` | Encode and decode base64 data |

## Reflection
Linux is the backbone of DevOps. Everything I learned here directly 
connects to what comes next — Docker containers run Linux, AWS EC2 
servers use these same commands daily, and Kubernetes manages Linux 
processes at scale. The Bandit challenge taught me to think like an 
engineer — not just running commands but understanding why they work.
